A minimal personal finance dashboard: every transaction with its category, weekly and monthly spending with AI advice, card perks, and new-card offers. Covers credit cards plus checking and savings accounts.

Data comes from [Era Context](https://era.app) and is stored in SQLite on your own server, reachable only by you.

## Features

- **Spending**: every transaction with amount and category. Change a category and choose to apply it to just that transaction or to every transaction from the same merchant.
- **Reports**: weekly (Monday start) and monthly totals by category, with advice generated by Claude. Tap a category to see its transactions.
- **Card perks**: earning rates and monthly, quarterly and yearly credits for each card, with checkboxes to track what you've used.
- **New-card offers**: current sign-up bonuses compared against the cards you already hold.
- **Accounts**: balances for checking and savings, income and card payments.

## How it works

- **Era Context**: the server is an MCP client to `https://context.era.app/mcp` and signs in with OAuth. No API key is needed. Open the page once, click "log in", authorize with your Era account, and the server refreshes the token from then on.
- **Sync**: every `SYNC_HOURS` hours the server pulls the last 14 days of transactions into SQLite. The page reads only the local copy, so opening it costs no Era calls. The page's refresh button triggers a sync at most once every 30 minutes. Era's Organize plan allows 1,000 MCP calls a month and each sync uses about 3, so the default of every 6 hours is roughly 360 a month. A newly linked account gets its full history on the next sync.
- **Categories, perk checkboxes and advice** are stored in SQLite (`data/dashboard.db`).
- **Advice**: the "generate advice" button appears only when `ANTHROPIC_API_KEY` is set.
- `web/index.html` is the same file as the claude.ai artifact version. `web/selfhost-shim.js` connects the page's data calls to this server.

## Deploy

Needs Docker and Docker Compose.

```bash
git clone https://github.com/skyicechuchu/finance-dashboard.git
cd finance-dashboard
cp .env.example .env      # set PUBLIC_URL; ANTHROPIC_API_KEY is optional
docker compose up -d --build
```

Open `PUBLIC_URL` in a browser and click the login link to authorize Era. The first sync pulls everything since `HISTORY_START`.

Update:

```bash
git pull && docker compose up -d --build
```

### Configuration (`.env`)

| Variable | Default | Meaning |
|---|---|---|
| `PUBLIC_URL` | `http://localhost:8080` | The address you open the dashboard at. Must match exactly; Era redirects back here after login. |
| `PORT` | `8080` | Port the server listens on. |
| `ANTHROPIC_API_KEY` | empty | Enables AI advice in reports. |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | Model used for advice. |
| `SYNC_HOURS` | `6` | Hours between syncs with Era. |
| `HISTORY_START` | `2026-04-01` | Earliest date pulled on the first sync. |
| `ERA_SCOPES` | empty | Optional space-separated OAuth scopes to request from Era. Empty uses Era's defaults. |

Changing `PUBLIC_URL` re-registers the OAuth client, so you'll need to log in to Era once more.

## Access: Tailscale recommended

`docker-compose.yml` binds the port to `127.0.0.1:8080` only, so nothing is exposed to the internet. Use Tailscale to reach it from your phone and laptop:

```bash
# on the server, after installing Tailscale and running `sudo tailscale up`
sudo tailscale serve --bg 8080
```

`tailscale serve status` shows an address like `https://your-machine.your-tailnet.ts.net`. Put it in `PUBLIC_URL` in `.env` and restart with `docker compose up -d`. Install Tailscale on your phone, sign in to the same account, and open that address.

Without Tailscale, Cloudflare Tunnel with Cloudflare Access (email verification) also works. Don't expose the dashboard to the internet behind a password alone.

## Backup

All state lives in `data/dashboard.db`; back up that one file. Deleting it signs out of Era and clears local data.

## Local development

```bash
npm install
npm start      # Node 22.13+, http://localhost:8080 by default
```

`npm start` reads `.env` if present and listens on `127.0.0.1` unless `HOST` is set.
